## Contributing
Contributions are welcome — especially translations, corrections, and additional biographical materials.

To contribute:
1. Fork the repository.
2. Create a branch named `feature/your-change`.
3. Add or edit files. If you add translations, put them in a folder named by the language (e.g., `/am/` for Amharic, `/om/` for Oromo, `/en/` for English) and include a README describing the source.
4. Commit your changes with a descriptive message and open a pull request.

Guidelines:
- Keep translations accurate and respectful.
- Cite sources when adding historical documents or photos.
- For text files, use UTF-8 encoding.
