## Contributing
Contributions and corrections are welcome.

Steps to contribute:
1. Fork the repository.
2. Create a branch for your changes: `git checkout -b feature/your-change`.
3. Add or edit files. For translations, create a folder named by the language code (e.g., `en/` for English) and include a README describing the source.
4. Commit your changes and open a pull request describing what you changed and why.

Guidelines:
- Keep text clear and respectful.
- Cite sources when adding historical documents or photos.
- Use UTF-8 encoding for text files.
